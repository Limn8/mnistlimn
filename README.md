# Digit Lab

학생이 숫자 한 개를 그리면 실제 MNIST 손글씨와 비교하는 웹 실험 도구입니다. 마우스, 펜, 터치를 지원합니다.

## 실행

```sh
npm install
npm run dev -- --port 5179
```

http://localhost:5179 에서 사용합니다. 배포 파일은 `npm run build`로 생성되는 `dist`입니다. 정적 호스팅으로 배포할 수 있으며 `/data` 경로를 사용하므로 사이트 루트에 배포합니다.

## 비교 방식

- MNIST 숫자별 300개, 총 3,000개의 균형 부분집합을 로컬에 포함합니다.
- 입력과 예시를 20픽셀 크기로 맞춘 뒤 28 × 28 이미지의 무게중심을 정렬합니다.
- `ml-knn`의 유클리드 거리 기반 k-NN, k=7로 숫자를 분류합니다. Web Worker에서 계산합니다.
- 숫자별 유사도는 각 숫자의 거리상 가장 가까운 예시를 기준으로 `100 * max(0, 1 - distance / sqrt(inputEnergy + referenceEnergy))`를 표시합니다. 정답 확률이 아닙니다.
- 겹침 지도는 0.2 밝기 임계값의 픽셀 집합을 비교합니다. 겹침 비율은 교집합 / 합집합입니다. 신경망 해석이나 인과적 설명이 아닙니다.
- 모든 비어 있지 않은 이미지를 0~9로 분류합니다. 글자·낙서의 의미를 인식하거나 거부하는 모델이 아닙니다.
- 손글씨는 서버에 전송하거나 저장하지 않습니다. PNG 저장은 사용자가 직접 선택합니다.

## 검증

`npm test`는 정규화·유사도·겹침·실제 MNIST 데이터 통합을 검사합니다. `node scripts/evaluate.mjs`는 학습 예시와 분리된 MNIST 400개를 평가합니다. 현재 379/400 (94.75%); 학생이 그린 입력의 정확도를 보장하는 수치는 아닙니다. `node scripts/browser-qa.mjs`는 실행 중인 사이트와 설치된 Edge를 이용해 화면 크기, 실제 그리기, 터치, 실행 취소, 비교 모드, 다운로드를 검사합니다.

## 출처

MNIST JS 배포: https://github.com/cazala/mnist (`mnist@1.1.0`). 배포 라이선스: MIT. 원본 데이터는 MNIST 손글씨 숫자 데이터베이스입니다. 전체 60,000개를 학습한 신경망이 아니라 명시된 3,000개 부분집합을 비교합니다. 데이터 재생성: `npm run data`.
