# Digit Lab

학생이 숫자 한 개를 그리면 실제 MNIST 손글씨와 비교하는 웹 실험 도구입니다. 마우스, 펜, 터치를 지원합니다.

## 실행

```sh
npm install
npm run dev -- --port 5179
```

http://localhost:5179 에서 사용합니다. 배포 파일은 `npm run build`로 생성되는 `dist`입니다. 정적 호스팅으로 배포할 수 있으며 `/data` 경로를 사용하므로 사이트 루트에 배포합니다.

## 비교 방식

- 원본 MNIST 학습 데이터 전체 60,000개를 포함합니다. 별도의 테스트 데이터 10,000개는 비교 예시에 포함하지 않습니다.
- 입력과 예시를 면적 평균 방식으로 20픽셀 크기에 맞춘 뒤 28 × 28 이미지의 무게중심을 정렬합니다.
- 압축 파일을 브라우저에서 해제해 8비트 픽셀로 보관하고, 획 밝기 > 0.2를 1, 나머지를 0으로 이진화합니다. 전체 60,000개와의 해밍거리(다른 픽셀 수)를 계산해 가장 가까운 7개를 찾고, `ml-knn`으로 다수결을 수행합니다. 이진 벡터의 제곱 유클리드 거리는 해밍거리와 정확히 같으므로 기존 거리 라이브러리를 재사용합니다. Web Worker에서 계산하고, 이전 계산 중에는 최신 입력만 대기시켜 요청 누적을 막습니다.
- 숫자별 픽셀 일치율은 각 숫자의 해밍거리가 가장 작은 예시를 기준으로 `100 * (1 - distance / 784)`를 표시합니다. 빈 배경도 포함하며 정답 확률이 아닙니다.
- 겹침 지도는 0.2 밝기 임계값의 픽셀 집합을 비교합니다. 겹침 비율은 교집합 / 합집합입니다. 신경망 해석이나 인과적 설명이 아닙니다.
- 모든 비어 있지 않은 이미지를 0~9로 분류합니다. 글자·낙서의 의미를 인식하거나 거부하는 모델이 아닙니다.
- 손글씨는 서버에 전송하거나 저장하지 않습니다. PNG 저장은 사용자가 직접 선택합니다.

## 검증

`npm test`는 정규화·유사도·겹침·실제 MNIST 데이터 통합을 검사합니다. `node scripts/evaluate.mjs`는 원본 테스트 분할에서 숫자별 처음 40개, 총 400개를 평가하고 `public/data/evaluation.json`에 기록합니다. 이 결과는 학생이 직접 그린 입력의 정확도를 보장하지 않습니다. `node scripts/browser-qa.mjs`는 실행 중인 사이트와 설치된 Edge를 이용해 화면 크기, 실제 그리기, 터치, 실행 취소, 비교 모드, 다운로드를 검사합니다.

## 출처

MNIST 원본 데이터의 CVDF 미러: https://github.com/cvdfoundation/mnist. 파일 출처와 SHA-256은 `public/data/provenance.json`에 기록합니다. 전체 학습 예시와 직접 비교하는 k-NN이며 신경망이 아닙니다. 데이터 재생성: `npm run data`.
